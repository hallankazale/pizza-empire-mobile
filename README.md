# Pizza Empire Mobile

Jogo mobile 3D de gerenciamento e evolução de uma pizzaria para Android.

## V0.1
Trigo → moinho → massa → bancada → pizza → forno → balcão → cliente → dinheiro.

## Direção técnica
- Unity 6 / C#
- Câmera isométrica
- Joystick mobile
- Interações automáticas por proximidade
- Visual low-poly original
- Upgrades, funcionários e expansão

## Estrutura inicial
- `Assets/Scripts/Core` — economia, itens e save
- `Assets/Scripts/Player` — movimento e inventário
- `Assets/Scripts/Production` — receitas e produção
- `Assets/Scripts/Tests` — testes automatizados

Próxima etapa: cena jogável, joystick, triggers das estações e cenário low-poly.
